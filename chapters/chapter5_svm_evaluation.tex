\chapter{SVM CLASSIFIER EVALUATION}

\section{Experimental Setup}

We evaluated the Support Vector Machine (SVM) classifier across both registered gene expression datasets: GSE19804 (balanced lung cancer, 120 samples) and GSE42568 (imbalanced breast cancer, 121 samples). The evaluation employed a 5-fold stratified cross-validation strategy with balanced class weighting and a linear kernel ($C = 1.0$).

The experimental framework comprised two distinct tracks:
\begin{itemize}
    \item \textbf{Path A (Baseline):} Linear SVM trained on the full high-dimensional feature space ($p = 54,675$) without feature selection.
    \item \textbf{Path B (Optimised):} Linear SVM trained on the genes retained by the selected statistical rule, with feature selection performed strictly \textit{inside} each training fold using \texttt{sklearn.pipeline.Pipeline}.
\end{itemize}

By placing the \texttt{FeatureSelector} inside the cross-validation pipeline, feature ranking and subset selection were computed exclusively on each training fold ($80\%$ of data), guaranteeing zero data leakage to the evaluation test fold ($20\%$ of data).

\subsection{Evaluation Metrics}

Each pipeline is scored on five folds and reported as mean $\pm$ standard deviation. Because the two datasets differ substantially in class balance, no single metric is sufficient on its own, so the following complementary measures are reported together:

\begin{itemize}
    \item \textbf{Accuracy} -- the overall proportion of correctly classified samples. On imbalanced data this metric can be misleadingly high if the classifier simply predicts the majority class.
    \item \textbf{Precision and Recall (Sensitivity)} -- precision is the proportion of predicted-positive samples that are true positives; recall (equivalently, sensitivity) is the proportion of true positives that are correctly identified.
    \item \textbf{Specificity} -- the proportion of true negatives correctly identified. This is the metric most sensitive to majority-class collapse, since a classifier that always predicts the positive class scores $0\%$ specificity regardless of its accuracy.
    \item \textbf{F1-Score} -- the harmonic mean of precision and recall, useful when the cost of false positives and false negatives is similar.
    \item \textbf{Matthews Correlation Coefficient (MCC)} -- a single balanced measure computed from all four confusion-matrix cells, ranging from $-1$ (total disagreement) through $0$ (random / majority-class guessing) to $+1$ (perfect prediction). MCC is regarded as the most reliable single indicator of classifier quality under class imbalance and is treated as the primary decision metric in this chapter whenever it conflicts with accuracy.
    \item \textbf{ROC-AUC} -- the area under the receiver operating characteristic curve, summarising the trade-off between sensitivity and the false-positive rate independently of the classification threshold.
\end{itemize}

\section{Imbalanced-Data Extensions and Model Tuning}

\subsection{Scope and Methodology}

The GSE42568 analysis was extended to test whether the poor minority-class performance was driven by classifier design or by imbalance. \textbf{These extensions were evaluated on the Welch's $t$-test path}.

The following variants of the Welch $t$-test pipeline were evaluated:
\begin{itemize}
    \item Baseline: default decision threshold (0.0), all genes with $p \leq 0.05$, $C = 1.0$
    \item SMOTE: fold-wise resampling applied during training
    \item Threshold tuning: Youden's $J$ statistic applied to decision-function scores
    \item $C$ tuning: inner-CV grid search for SVM regularization ($C \in \{0.01, 0.1, 1, 10, 100\}$)
    \item Logistic regression: alternative classifier using the same p-qualified genes
    \item Random forest: alternative classifier using the same p-qualified genes
    \item XGBoost: alternative non-linear ensemble classifier using the same p-qualified genes
\end{itemize}

The resulting experiments show that nominal p-value selection is not sufficient for GSE42568: the baseline and most extensions collapse to predicting cancer, while the two-gene BH-FDR path in the main comparison is the only Path B configuration with positive MCC.

\medskip

\textbf{\textsf{Interpretation of Table~\ref{tab:gse42568_extensions}:}} Under Welch selection, the extension variants retain the selected feature set and mostly predict the majority class. Notably, applying SMOTE to synthetically oversample the minority class during training completely failed to rescue the model's performance. The SMOTE variant yielded $100\%$ Recall but $0\%$ Specificity, producing an MCC of exactly $0.0000$. This indicates that even with synthetically balanced training batches, the high-dimensional noise from the 6,706 retained Welch features overpowered the synthetic minority samples, causing the SVM to revert to predicting the majority class (cancer) for every test sample.

Threshold tuning is the only exception to this collapse: it raises Specificity to $13.33\%$ and MCC to $0.0512$, while preserving ROC-AUC at $0.5882 \pm 0.1511$. However, as the table reflects, when the true minority class is tiny ($n=17$), neither synthetic resampling (SMOTE) nor alternative classifiers provide a stable remedy without more aggressive feature reduction. Threshold tuning improves the mean MCC modestly, but its standard deviation is $0.2575$, so the apparent gain requires more analysis.

\subsection{Performance Analysis on GSE19804}

Figure~\ref{fig:gse19804_comparison} visualises the three headline metrics side by side for every pipeline. Because GSE19804 is class-balanced, accuracy, MCC, and ROC-AUC largely agree on which pipelines perform well, which is itself a useful sanity check that the balanced setting is behaving as expected.

\begin{enumerate}
    \item \textbf{Distinct SVM-RFE result:} RFE retains 120 features and lowers Accuracy to $92.50\%$ and MCC to $0.8554$.
    \item \textbf{RF, XGBoost, and LASSO results:} RF matches the baseline classification metrics while improving ROC-AUC to $0.9819$; LASSO reaches ROC-AUC $0.9847$. Notably, the \textbf{XGBoost Importance} wrapper achieves the highest overall performance on GSE19804 across all configurations, reaching $97.50\%$ Accuracy and $0.9530$ MCC.
    \item \textbf{Equal scores here are not a red flag:} RF importance (333 features) matches Path A and the ANOVA filter (25,707 features) on Accuracy and MCC despite retaining under 1.3\% as many genes. Because GSE19804 is a strongly class-separated, near-linearly-separable dataset, several very different feature subsets can each saturate the same 5-fold accuracy/MCC ceiling. SVM-RFE's drop to $92.50\%$ accuracy confirms that the selectors are behaving independently. XGBoost produced a better manifold that improves accuracy.
    \item \textbf{statistical paths:} Welch, ANOVA, and BH-FDR retain large sets and have Accuracy $=95.00\%$; their MCC is $0.9013$.
    \item \textbf{Alternative Classifiers:} As a baseline check on classifier choice, substituting the linear SVM for an XGBoost classifier on the Welch's $t$-test selected features improved Accuracy slightly to $95.83\%$ and MCC to $0.9240$, demonstrating that non-linear ensemble methods can provide a marginal gain even on highly separable balanced datasets.
\end{enumerate}

\subsection{Path A Majority-Class Collapse vs Path B Recovery}

As shown in Table~\ref{tab:gse42568_svm_results} and Figure~\ref{fig:gse42568_comparison}, the Path A baseline on GSE42568 suffered complete majority-class collapse due to extreme dimensionality ($p=54{,}675$) relative to the sample size ($n=121$), compounded by severe class imbalance ($104$ cancer vs. $17$ normal, i.e.\ $86\%$ cancer). The raw SVM predicted every sample as cancer, yielding an inflated accuracy ($85.97\%$) that at first glance looks competitive with the balanced-dataset results, but a \textbf{Recall/Sensitivity of $100\%$} paired with \textbf{Specificity $=0.0\%$} shows the model never once identified a normal sample. This is confirmed by \textbf{MCC $= 0.0000$}, the value expected under pure majority-class guessing, and by the near-chance \textbf{ROC-AUC of $0.4569$} both indicating the classifier has learned no discriminative signal at all. Accuracy alone would have concealed this failure entirely, which is precisely why MCC and specificity are reported as primary metrics for this dataset.

Applying Welch $t$-test selection inside the CV folds (\texttt{path\_b\_filter\_ttest}) does not break the majority-class collapse: accuracy is $84.30\%$, but Specificity remains $0\%$ and MCC is $-0.0315$.

The BH-FDR-ranked selector is the only Path B method that retains a very small feature set: two genes survive BH correction, yielding MCC $=+0.0269$ and Specificity $=38.33\%$. Notably, XGBoost Importance drastically reduces the majority-class bias compared to SVM-RFE (improving Accuracy from 56.9\% to 76.0\%), though its MCC remains near zero at $-0.0178$. Thus, the larger p-qualified set still tends toward majority-class collapse, while algorithmic selection changes the balance and the conservative two-gene BH-FDR set remains strongest by MCC, although its mean is small and noisy.

Taken together, the BH-FDR selector is the strongest Path B variant on GSE42568 by MCC ($+0.0269$), but it remains close to chance. The XGBoost wrapper is the most stable of the embedded/wrapper methods but a strict multiple-testing threshold is more useful here than retaining thousands of nominally significant genes.

\section{Discussion and Summary}

The empirical evaluation leads to four major findings:
\begin{enumerate}
    \item \textbf{On Balanced Datasets (GSE19804):} All Path B methods match the Path A classifier at Accuracy $=95.00\%$ and MCC $=0.9013$; their ROC-AUC values differ only slightly ($0.9792$--$0.9806$). However, \textbf{XGBoost Importance} as a feature selector outperforms all other configurations, reaching $97.5\%$ Accuracy and $0.9530$ MCC.
    \item \textbf{On Imbalanced Datasets (GSE42568):} The Welch, ANOVA, wrapper, and LASSO paths all have Specificity near $0\%$ and negative or zero MCC. The two-gene BH-FDR path is strongest by MCC ($+0.0269$), but remains close to chance.
    \item \textbf{Selection-policy effect:} Larger nominally significant gene sets collapse toward majority-class prediction, while strict BH-FDR filtering retains only two genes and provides the best Path B balance. the tree-based wrapper approach which is the XGBoost, show signs of mitigating this collapse but still struggle against the severe class imbalance.
    \item \textbf{Leakage Prevention:} Embedding feature selection strictly within cross-validation folds via scikit-learn \texttt{Pipeline} ensures rigorous, unbiased validation of high-dimensional genomic classifiers, and is what allows the majority-class collapse on GSE42568 to be detected in the first place, had feature selection been performed on the full dataset before splitting, the resulting optimistic bias could have masked this failure mode.
\end{enumerate}

\subsection{Limitations}

The principal limitations of the imbalanced GSE42568 analysis are:

\begin{enumerate}
    \item \textbf{Regenerated extension rows:} Threshold tuning improved MCC to $0.0512 \pm 0.2575$ and Specificity to $13.33\%$, while ROC-AUC remained $0.5882 \pm 0.1511$. Alternate classifiers including Logistic Regression, Random Forest, and XGBoost all failed to correct the majority-class bias, yielding specificity of $0.0\%$ and negative or zero MCCs.
      
    \item \textbf{Scope of extensions:} The SMOTE, threshold tuning and $C$ tuning (Table~\ref{tab:gse42568_extensions}) were evaluated only on the Welch $t$-test feature selector. The other five Path B methods were not extended, so it's unknown whether these tuning strategies would improve their performance on GSE42568.
\end{enumerate}

Despite these limitations, the results demonstrate failure of the full-dimensional baseline (Path A) on GSE42568 and show that feature selection changes the balance between sensitivity and specificity.
