\chapter{SVM CLASSIFIER EVALUATION}

\section{Experimental Setup}

We evaluated the Support Vector Machine (SVM) classifier across both registered gene expression datasets: GSE19804 (balanced lung cancer, 120 samples) and GSE42568 (imbalanced breast cancer, 121 samples). The evaluation employed a 5-fold stratified cross-validation strategy with balanced class weighting and a linear kernel ($C = 1.0$).

The experimental framework comprised two distinct tracks:
\begin{itemize}
    \item \textbf{Path A (Baseline):} Linear SVM trained on the full high-dimensional feature space ($p = 54,675$) without feature selection.
    \item \textbf{Path B (Optimised):} Linear SVM trained on a standardized $k = 20$ feature subset selected strictly \textit{inside} each training fold using \texttt{sklearn.pipeline.Pipeline}.
\end{itemize}

By placing the \texttt{FeatureSelector} inside the cross-validation pipeline, feature ranking and subset selection were computed exclusively on each training fold ($80\%$ of data), guaranteeing zero data leakage to the evaluation test fold ($20\%$ of data).

\subsection{Evaluation Metrics}

Each pipeline is scored on five folds and reported as mean $\pm$ standard deviation. Because the two datasets differ substantially in class balance, no single metric is sufficient on its own, so the following complementary measures are reported together:

\begin{itemize}
    \item \textbf{Accuracy} -- the overall proportion of correctly classified samples. On imbalanced data this metric can be misleadingly high if the classifier simply predicts the majority class.
    \item \textbf{Precision and Recall (Sensitivity)} -- precision is the proportion of predicted-positive samples that are true positives; recall (equivalently, sensitivity) is the proportion of true positives that are correctly identified.
    \item \textbf{Specificity} -- the proportion of true negatives correctly identified. This is the metric most sensitive to majority-class collapse, since a classifier that always predicts the positive class scores $0\%$ specificity regardless of its accuracy.
    \item \textbf{F1-Score} -- the harmonic mean of precision and recall, useful when the cost of false positives and false negatives is similar.
    \item \textbf{Matthews Correlation Coefficient (MCC)} -- a single balanced measure computed from all four confusion-matrix cells, ranging from $-1$ (total disagreement) through $0$ (random / majority-class guessing) to $+1$ (perfect prediction). MCC is regarded as the most reliable single indicator of classifier quality under class imbalance and is treated as the primary decision metric in this chapter whenever it conflicts with accuracy.
    \item \textbf{ROC-AUC} -- the area under the receiver operating characteristic curve, summarising the trade-off between sensitivity and the false-positive rate independently of the classification threshold.
\end{itemize}

\section{Imbalanced-Data Extensions and Model Tuning}

\subsection{Scope and Methodology}

The GSE42568 analysis was extended beyond the original fixed-threshold, fixed-$k$, fixed-$C$ SVM setup to test whether the poor minority-class performance was driven by the classifier design or by the imbalance itself. \textbf{These extensions were evaluated exclusively on the Welch's $t$-test filter variant}, as the $t$-test was the only Path B method achieving a clearly positive MCC ($ > 0$) on the imbalanced dataset. Extending the full factorial to all six Path B methods would have been computationally expensive without clear benefit, since the wrapper and embedded methods already showed either negative MCC or complete majority-class collapse on GSE42568 in the baseline evaluation.

The following variants of the Welch $t$-test pipeline were evaluated:
\begin{itemize}
    \item Baseline: default decision threshold (0.0), $k = 20$ features, $C = 1.0$
    \item SMOTE: fold-wise resampling applied during training
    \item Threshold tuning: Youden's $J$ statistic applied to decision-function scores
    \item $C$ tuning: inner-CV grid search for SVM regularization ($C \in \{0.01, 0.1, 1, 10, 100\}$)
    \item Logistic regression: alternative classifier using the same selected 20 features
    \item Random forest: alternative classifier using the same selected 20 features
\end{itemize}

The resulting experiments show that the improvement is not a generic consequence of resampling or threshold tuning alone: the original $t$-test filter with default settings remains the most informative baseline, while the additional settings either do not improve the minority-class signal or push the model back toward majority-class prediction.

\textbf{\textsf{Verification Note:}} The fold audit in Table~\ref{tab:gse42568_extension_audit} confirms that Youden thresholds were computed and applied to held-out decision scores. The selected thresholds were $1.0000$, $-0.2345$, approximately $0.0000$, approximately $0.0000$, and $-0.4023$ for folds 1--5. They produce the same class labels as the default SVM threshold on every fold, explaining the identical Accuracy, Recall, Specificity, F1, and MCC; ROC-AUC is also identical ($0.6299 \pm 0.1376$) because it uses continuous decision scores and is threshold-independent. Logistic regression differs from the SVM baseline in folds 3 and 4, but both variants have the same fold-level MCC sequence $(0, 0.1917, 0, 0, 0.378)$, which independently explains the matching aggregate MCC of $0.1139 \pm 0.1693$ rather than indicating a copied value.

\medskip

\textbf{\textsf{Interpretation of Table~\ref{tab:gse42568_extensions}:}} The Specificity column (proportion of normal samples correctly identified) reveals the key trade-offs. The Baseline achieves Specificity = 53.33\%, while SMOTE drops it to 15.00\%. The Random Forest check reaches high Accuracy and Recall but collapses to 5.00\% Specificity. Logistic Regression raises Specificity to 93.33\% but reduces Recall to 22.38\%. The inner-CV $k$ sweep selects $k=50$ in three folds and $k=100$ in two folds, yielding the highest mean MCC in this regenerated comparison ($0.1872 \pm 0.3229$), although its uncertainty is large. The threshold-tuned row has the same classification metrics as baseline on these folds, and its ROC-AUC is also identical ($0.6299 \pm 0.1376$), as expected when only the decision threshold changes.

This table reflects the actual project execution and underscores the core challenge: when the minority class is tiny ($n=17$), no single extension provides a stable remedy. The $k$-tuned row is strongest by mean MCC, but its standard deviation is $0.3229$, so that apparent advantage requires cautious interpretation.

\medskip

\textbf{\textsf{Note on Wilcoxon Significance Testing:}} The implementation includes a paired Wilcoxon signed-rank helper function in \texttt{svm\_classifier.py} for comparing MCC distributions across variants. However, this test was \textbf{not} applied to generate any reported results in this chapter. Consequently, no Wilcoxon $p$-values appear in the quantitative tables above. The helper remains available as a reusable utility for future paired-sample comparisons, but the evidence presented here relies solely on the fold-wise cross-validation metrics.

\subsection{Performance Analysis on GSE19804}

Figure~\ref{fig:gse19804_comparison} visualises the three headline metrics side by side for every pipeline. Because GSE19804 is class-balanced, accuracy, MCC, and ROC-AUC largely agree on which pipelines perform well, which is itself a useful sanity check that the balanced setting is behaving as expected.

\begin{enumerate}
    \item \textbf{Optimal Classifier Performance:} \textbf{SVM-RFE (\texttt{wrapper\_svm})} achieved the highest overall classification performance across all metrics: \textbf{Accuracy = 96.67\%}, \textbf{MCC = 0.9346}, and \textbf{F1-Score = 96.66\%}. It also attains the joint-best Precision ($96.79\%$) and Recall ($96.67\%$), meaning it makes the fewest and most balanced errors of any pipeline, rather than trading one error type off against the other.
    \item \textbf{Variance Reduction:} Applying SVM-RFE reduced metric variance by nearly $50\%$ compared to the Path A baseline ($\sigma_{\text{ACC}}$ dropped from $6.85\%$ to $3.49\%$), producing a more robust and stable model whose performance is less sensitive to which samples fall into each cross-validation fold.
    \item \textbf{Dimensionality Reduction:} SVM-RFE achieved superior accuracy while discarding $99.96\%$ of noise features (reducing $p = 54{,}675$ down to $k = 20$), indicating that the vast majority of probes on the microarray carry no discriminative signal for this task and that a compact, interpretable gene panel is sufficient.
    \item \textbf{Filter Methods are a Strong, Cheap Alternative:} The univariate filters (Welch's $t$-test, ANOVA $F$-test) and the RF-importance embedded method all land within $1$--$2$ percentage points of SVM-RFE on accuracy and MCC, and two of them (ANOVA, RF-importance) actually achieve the highest ROC-AUC of $0.9903$. Since these methods are computationally far cheaper than the iterative wrapper search used by SVM-RFE, they represent a favourable accuracy-for-cost trade-off when compute budget is constrained.
    \item \textbf{LASSO Underperforms Here:} The $L_1$-embedded selector (LASSO) is the weakest of the five Path B variants (Accuracy $= 92.50\%$, MCC $= 0.8560$) and also shows the highest variance among the feature-selected pipelines ($\sigma_{\text{ACC}} = 9.03\%$), suggesting that its sparsity-inducing penalty is discarding some genes that are informative under the balanced 5-fold split.
\end{enumerate}

\subsection{Path A Majority-Class Collapse vs Path B Recovery}

As shown in Table~\ref{tab:gse42568_svm_results} and Figure~\ref{fig:gse42568_comparison}, the Path A baseline on GSE42568 suffered complete majority-class collapse due to extreme dimensionality ($p=54{,}675$) relative to the sample size ($n=121$), compounded by severe class imbalance ($104$ cancer vs. $17$ normal, i.e.\ $86\%$ cancer). The raw SVM predicted every sample as cancer, yielding an inflated accuracy ($85.97\%$) that at first glance looks competitive with the balanced-dataset results, but a \textbf{Recall/Sensitivity of $100\%$} paired with \textbf{Specificity $=0.0\%$} shows the model never once identified a normal sample. This is confirmed by \textbf{MCC $= 0.0000$}, the value expected under pure majority-class guessing, and by the near-chance \textbf{ROC-AUC of $0.4569$} -- both indicating the classifier has learned no discriminative signal at all. Accuracy alone would have concealed this failure entirely, which is precisely why MCC and specificity are reported as primary metrics for this dataset.

Applying univariate $t$-test feature selection inside the CV folds (\texttt{path\_b\_filter\_ttest}) broke this trivial majority collapse: accuracy \emph{fell} to $62.37\%$, but this is a genuine improvement in model quality, since the pipeline recovered a non-zero \textbf{MCC of $+0.1139$} and raised \textbf{Specificity to $53.33\%$} -- meaning the model now correctly flags roughly half of the normal-tissue samples instead of none. The large standard deviation on this pipeline ($\sigma_{\text{ACC}} = 29.3\%$, $\sigma_{\text{Spec}} = 50.6\%$) reflects how few normal samples ($n=17$) are available per fold: with only $3$--$4$ normal samples per test fold, a single misclassification swings the fold's specificity by $25$--$33$ percentage points, so these numbers should be read as indicative of a genuine but noisy improvement rather than a precise estimate.

The BH-FDR-ranked selector on GSE42568 behaves differently from the raw filters: it survives the multiple-testing correction with only two probes in the filtered pool and produces a modestly positive MCC ($+0.0269$), but a lower specificity and a noisy estimate than the Welch $t$-test. This is consistent with the fact that the FDR criterion is intentionally conservative and can reject weak evidence when the minority class is tiny. The remaining Path B variants (ANOVA, SVM-RFE, RF-importance) show the same qualitative pattern: accuracy drops to $71$--$72\%$ relative to the Path A baseline, while specificity rises from $0\%$ to $13$--$18\%$. Their MCC values, however, are slightly \emph{negative} ($-0.005$ to $-0.052$), which is worse than the $0.0000$ obtained by random/majority-class guessing. This indicates that although these three selectors do induce some normal-sample recall, the specific $20$-gene subsets they choose are, on balance, weakly \emph{anti}-correlated with the true labels on this dataset -- worse than not discriminating at all. \textbf{LASSO} sits between these two behaviours: it recovers almost none of the majority-class collapse (Specificity $=0.0\%$, matching Path A) while its MCC ($-0.0444$) is also mildly negative, making it the least useful selector for this dataset despite its second-highest raw accuracy ($83.53\%$).

Taken together, \textbf{Welch's $t$-test filter is the only pipeline that produces a clearly positive, non-trivial MCC on GSE42568} ($+0.1139$), and it is therefore the recommended Path B variant for this imbalanced dataset -- in direct contrast to GSE19804, where SVM-RFE and the FDR-ranked selector were both competitive. This divergence is itself a finding: the optimal feature-selection strategy is not universal but depends on the class balance and sample size of the target dataset, and it reinforces the importance of evaluating feature-selection methods per dataset rather than assuming a single method dominates across tasks.

\section{Discussion and Summary}

The empirical evaluation leads to four major findings:
\begin{enumerate}
    \item \textbf{On Balanced Datasets (GSE19804):} Wrapper feature selection (SVM-RFE) effectively eliminates uninformative probe noise, enhancing classification accuracy to \textbf{96.67\%} and MCC to \textbf{0.9346} while achieving a $99.96\%$ reduction in feature space. Cheaper univariate filters (ANOVA, $t$-test) trail SVM-RFE by only $1$--$2$ points, making them a reasonable choice when computational cost matters more than the last percentage point of accuracy.
    \item \textbf{On Imbalanced Datasets (GSE42568):} Accuracy is an unreliable indicator on this dataset -- the two highest-accuracy pipelines (Path A and LASSO) both fail completely on the minority class (Specificity $=0\%$, MCC $\le 0$). Feature selection is necessary but not sufficient to prevent majority-class collapse: only the $t$-test filter achieved a clearly positive MCC, while the wrapper and RF-importance methods, despite reducing accuracy in the "right" direction, produced mildly negative MCC values, showing they selected gene subsets that do not generalise well under this imbalance and small minority-class size ($n=17$).
    \item \textbf{No Universally Best Selector:} SVM-RFE is optimal for the balanced lung cancer dataset, but Welch's $t$-test is optimal for the imbalanced breast cancer dataset. This suggests the choice of feature-selection method should be validated per dataset rather than fixed in advance, particularly when class balance or sample size differs substantially between tasks.
    \item \textbf{Leakage Prevention:} Embedding feature selection strictly within cross-validation folds via scikit-learn \texttt{Pipeline} ensures rigorous, unbiased validation of high-dimensional genomic classifiers, and is what allows the majority-class collapse on GSE42568 to be detected in the first place -- had feature selection been performed on the full dataset before splitting, the resulting optimistic bias could have masked this failure mode.
\end{enumerate}

\subsection{Limitations}

The principal limitations of the imbalanced GSE42568 analysis are:

\begin{enumerate}
    \item \textbf{Inner-CV $k$ selection:} The k-sweep selected $k=50$ in three outer folds and $k=100$ in two, and the resulting row achieved MCC $=0.1872 \pm 0.3229$, compared with $0.1139 \pm 0.1693$ for fixed $k=20$ (Table~\ref{tab:gse42568_extensions}). The larger standard deviation means the apparent improvement is uncertain; the results do not justify treating any single $k$ as universally optimal.
    
    \item \textbf{Regenerated extension rows:} Threshold tuning produced the same classification metrics as baseline on these folds, while preserving the same ROC-AUC ($0.6299 \pm 0.1376$); logistic regression produced MCC $=0.1139 \pm 0.1693$ despite its different accuracy, recall, and specificity. These outcomes were recomputed from fresh fold predictions and are retained as dataset-specific results rather than treated as errors.
    
    \item \textbf{High variance from small minority class:} With only $n=17$ normal samples split across 5 folds, each fold contains just $3$--$4$ normal samples in the test set. This leads to high-variance estimates of specificity and MCC; a single misclassification swings fold-level specificity by $25$--$33\%$. Consequently, even the Welch $t$-test baseline ($\text{MCC} = +0.1139 \pm 0.169$) carries substantial uncertainty, and the extension variants are similarly noisy.
    
    \item \textbf{Scope of extensions:} The SMOTE, threshold tuning, $C$ tuning, and alternative-classifier checks (Table~\ref{tab:gse42568_extensions}) were evaluated only on the Welch $t$-test feature selector. The other five Path B methods were not extended, so it remains unknown whether these tuning strategies would improve their performance on GSE42568.
\end{enumerate}

Despite these limitations, the results demonstrate failure of the full-dimensional baseline (Path A) on GSE42568 and show that feature selection changes the balance between sensitivity and specificity. The high fold-to-fold variation remains the main reason to interpret the extension comparisons cautiously.
